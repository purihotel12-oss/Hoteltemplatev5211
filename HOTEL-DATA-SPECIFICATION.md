# HOTEL DATA SPECIFICATION

Supply only verified information. Omit fields that are unavailable.

## Core
- Hotel name/legal name/short name
- tagline
- property type
- descriptions
- logo/favicon
- address/contact
- booking mode and verified URL

## Rooms
For each room: id, slug, name, descriptions, images, alt text, occupancy, bed, size, view, bathrooms, amenities, facilities, price if verified, meal plan, policies and FAQs.

## Images
Use descriptive filenames. Recommended: WebP/AVIF, responsive widths, explicit dimensions, meaningful alt text. Avoid `IMG001.jpg`-style names.

## SEO
Provide site URL, title, meta description, canonical rules, OG image and robots directives. The site URL must be the hotel's authoritative production domain.

## Policies
Provide hotel-approved privacy, refund/cancellation, terms and cookie content. Template legal text is not production legal advice.
