# V5.1 DESIGN UPGRADE

This release specifically upgrades the visual/UI layer from the earlier V5 foundation.

## Target qualities
- Premium editorial hospitality feel
- Full-bleed hero and image-led storytelling
- Strong display typography with restrained body typography
- Chapter-style navigation labels
- Asymmetric, magazine-like grids
- Room cards with image-first hierarchy
- Floating booking bar
- Clear conversion hierarchy
- Trust/fraud notice
- Destination/local discovery sections
- Refined footer
- Responsive mobile navigation
- Reduced-motion support
- Keyboard-visible focus states
- Minimal client-side JavaScript

## Reference-derived principles
The Machan's current site emphasizes destination storytelling, accommodation discovery, services/experiences, guest words, a final booking CTA and official-channel safety messaging.

V5.1 uses those broad hospitality information-architecture lessons while deliberately using original structure, copy, graphics and styling. The project is not a clone of either reference.
